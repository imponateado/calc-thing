# Bank Limit Calculator

This project is a simple web-based tool designed to help manage and calculate bank-related limits. It allows users to input data about banks and their limits, and then calculates totals across all entered data. The project uses **HTML**, **Bootstrap**, and **JavaScript** to deliver a responsive and interactive interface.

## Features

- **Add Bank Details**: Input data such as bank name, total limit, used limit, and available limit.
- **Automatic Calculation**: Computes the total, used, and available limits across all banks.
- **Dynamic Display**: Displays the data in a neatly formatted table.
- **Responsive Design**: Uses Bootstrap for styling and responsiveness.

## How It Works

1. Fill in the bank details:
   - Bank name
   - Total limit
   - Used limit
   - Available limit
2. Click the `➕` button to add the data.
3. The app dynamically updates the table with the entered data and calculates:
   - Total limit
   - Total used limit
   - Total available limit
4. View the results in the input fields below the table.

## Technologies Used

- **HTML5**: Markup for the structure of the web page.
- **Bootstrap 5**: For styling and responsive design.
- **JavaScript**: For dynamic functionality and calculations.

## Installation

To use this project:

1. Download or clone this repository.
2. Open the `index.html` file in your preferred web browser.

## Usage

1. Enter the details of each bank in the provided fields.
2. Click the `➕` button to add them to the list.
3. Check the calculated totals below the table.

### Input Form
- Fields: Bank name, total limit, used limit, available limit.

### Results Table
- Displays the bank details and updates dynamically.

### Calculations
- Automatically computes the totals across all banks entered.
